# RiverRoo — the self-guided RuvNet learning story

Version 1.5.0. Permanent public URL: https://riverroo-poker-story.vercel.app/

The eight chapters introduce the beginner, research question and ten-ability framework; the full-hand prototype; RuvNet Brain discovery of rUv poker implementations; memory versus learning; a bounded feedback-selection result; and the next tests. The story defines its tools, units, provenance and limitations without a presenter.

The new full-hand experiment is separate from the original learner and earlier restricted memory test. It demonstrates offline parameter calibration against one novice opponent, not expert poker or a causal advantage from vector retrieval. The playable UI uses its default setting. Poker-darwin integration remains unfinished.

Receipts: public/evidence/learning-proof.html. Full experiment source and dependencies: source/fullbot/. The preregistration and result files are intentionally write-protected against accidental replacement; use a new output prefix for any new run.
