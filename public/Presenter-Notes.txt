The story
1. Meet an experimental poker agent with no strategy.
2. Start with a research question: what should a capable player learn?
3. Turn the recorded ten-ability framework into an inspectable curriculum.
4. Build a full-hand environment with legal decisions and showdown.
5. Search RuvNet Brain and discover rUv’s existing poker implementations.
6. Distinguish remembering experience from learning through feedback.
7. Compare two full-hand heuristic settings on unseen test runs.
8. Explain the integrations and stronger tests that come next.

Evidence boundaries
The original completed Ruflo research report was not recovered. The ten areas are documented in a 9:04 AM build prompt and the 10 AM engineering checkpoint.

The new result compares two settings of the newer full-hand heuristic. It is not a continuous learning curve from the original uninformed agent. Five settings each played 128 training hands, for 640 total. A separate test used 256 seeds from both seats, or 512 hands per policy.

The default averaged 4.64746 simulated big blinds per hand; the selected setting averaged 7.46777. The paired gain was 2.82031, with a normal-approximation 95% interval of [1.14400, 4.49662]. This result applies to one weak novice opponent only.

The native RVF file stored 641 vectors and returned the selected-policy marker after reopening. The explicit selection code learned parameters; an independent performance benefit from vector retrieval was not measured. No overall ten-ability improvement is claimed. Poker-darwin integration remains unfinished. The playable browser demo uses its default setting.
