What learned?

An explicit search selected aggressionThreshold0.60,callMargin0.12,potFraction0.90 from five fixed configurations using training feedback. This is bounded parameter calibration, not a self-play neural learner or evidence of mastery across the ten attributes.

What did RuVector do?

The native RVF database accepted641vectors:640training experiences and the selected-policy marker. The file was closed and reopened; selected-policy-3 was retrieved at distance0 and its corresponding configuration used in an actual decision. The parent independently reopened the file on RuOS and reproduced the lookup. RVF stores and recalls; the feedback-selection code performs the optimisation. The gain is not an isolated causal benefit of vector retrieval.

Limits

One seeded novice opponent,100bbfresh stacks,60equity samples perdecision. One training selection and one holdout set; no independent trainingreplicates. No strong-player, multi-opponent, GTO, tournament, all-ten-attribute, or continually-adapting policy claim. The existing playable UI does not load this experiment’s selected setting.
